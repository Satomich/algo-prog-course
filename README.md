Контрольные вопросы
Почему программа может узнать имя компьютера, хотя вы не писали его в коде?
Потому что значение имени компьютера было вписано заранее

Какую роль играет операционная система, когда программа запрашивает у неё сведения?
Управляет доступом к процессору, памяти, файлам.

Что означает «64-битная ОС»?
64-битная операционная система использует 64-битную архитектуру и способна работать с гораздо большим адресным пространством, чем классическая 32-битная система.

Что показывает Environment.ProcessorCount и обязательно ли это число совпадает с числом физических ядер?
Количество процессоров, которое не обязательно должно совпадать с количеством ядер

Чем память процесса (WorkingSet) отличается от всей оперативной памяти компьютера?
Память процесса - это количество задействованной памяти из оперативной памяти. Оперативная память в свою очередь это общее количество доступной памяти у компьютера, распределяемое на различные процессы.

Почему одна и та же программа без изменений в коде может показать разные результаты на разных компьютерах?
Из-за разницы в комплектующих у различных компьютеров

Итоговый вывод
Программа, ОС и компьютер неразрывно связаны в ходе выполнения процессов. ОС обрабатывает данные нужные для работы и управляет доступом к процессору, памяти и файлам. Программа в свою очередь выполняет ту или иную задачу, получая нужные для неё сведения благодаря .NET. Также во время работы программы создаётся отдельный процесс - отдельное окружение со своей памятью.

Ответ на итоговый вопрос: Разница в результатах на разных компьютерах при условии одинакового кода исходит из-за наличия у разных компьютеров разных комплектующих


«ПР1. Ответы на контрольные вопросы»

1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки
зрения того, когда обнаруживаются ошибки?
C#: Ошибки обнаруживаются во время компиляции. Python: Ошибки обнаруживаются во время выполнения. 

2. Что делает команда dotnet run на самом деле — из каких двух шагов она состоит?
Команда состоит из двух этапов: компилирование кода в исполняемый файл и запуск этого файла

3. Зачем нужны папки bin/ и obj/ и почему их не нужно хранить в Git?
bin и obj это папки, где хранятся скомпилированные файлы и промежуточные файлы, созданные во время сборки проекта. Хранение этих папок в репозитории Git приведет к тому, что каждый разработчик будет иметь свою собственную версию скомпилированных файлов, что создаст проблемы при совместной работе.

4. В чём разница между git commit и git push?
git commit: Создает локальную "временную запись" изменений в вашем репозитории. git push: Отправляет ваши локальные коммиты из вашего ветки на удаленный репозиторий

5. Чем отличаются конкатенация строк через + и интерполяция через $"..."? Какой
способ предпочтительнее и почему? 
Конкатенация (+): Простая конкатенация строк требует явного преобразования типов данных в строки перед объединением.
Интерполяция ($"..."): Более современный и удобный способ, который позволяет вставлять значения переменных непосредственно в строку, используя фигурные скобки, именно поэтому и является более предпочтительным, так как гораздо удобнее.

6. Что произойдёт, если разделить int на int, если результат должен быть дробным?
Как это исправить?
При таком делении результатом будет целое число и дробная часть будет отброшена. Чтобы получить дробную часть нужно заменить один из int на double

7. Чем const отличается от обычной переменной? Приведите свой пример, когда
стоит использовать const. 
Const обозначает постоянную переменную, которая никак не изменится в ходе выполнения кода. Const можно использовать для обозначения математических и физических постоянных величин, таких  как например число Пи и коэфицент постоянного падения

8. Что такое top-level statements и чем они отличаются от классического class
Program{ static void Main() }?
Top-level statements: позволяют определять переменные, методы и другие элементы кода вне класса Program.
class Program { static void Main() }: традиционный способ организации программы на C#.
